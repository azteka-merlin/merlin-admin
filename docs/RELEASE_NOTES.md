# Novidades do Launcher

A pagina **Novidades / Changelog** configura releases Major ou Standard para o Launcher.

- Preencha sempre pt-BR; os demais idiomas sao opcionais e usam fallback no Launcher.
- Publicar torna a release elegivel para clientes autenticados; despublicar remove a elegibilidade.
- A arte e opcional, sem crop, e o upload passa pela API (maximo 12 MB).
- O campo de versao deve corresponder exatamente a versao do Launcher para abertura automatica.

O painel nao decide leitura, badge ou cache: essas regras pertencem ao Launcher/API.
