# Documentacao do Merlin Admin

Use esta pasta como fonte da documentacao do painel.

1. `UP.md` — desenvolvimento, build e deploy pelo projeto da API.
2. `CONTEXT.md` — arquitetura, rotas e fluxos do painel.
3. `ECOSYSTEM.md` — limites entre Admin, API, site publico e Launcher.
4. `SPECIAL_CORRECTION.md` — cadastro e contrato do override de correcao com token de licenca.
5. `PLANOS_VISUAL.md` — como usar a POC de planos apenas como referencia visual.
6. `RELEASE_NOTES.md` — gestao do changelog enviado ao Launcher.

As regras operacionais de planos e acesso antecipado ficam em `../Merlin-api/docs/PLANO_TIERS_OPERACAO.md`; o Admin apenas as configura, nunca as decide no navegador.

Regra de codigo aberto: nunca adicionar credenciais, dados de clientes, chaves de licenca, IDs privados de infraestrutura ou exports de producao.
